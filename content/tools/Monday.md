# Monday.com

## Overview
Monday.com is a project management platform designed to help teams organize assignments, collaborate, and track project progress. It uses customizable boards that display tasks, deadlines, responsibilities, and project statuses in an organized format. Its boards are more visual than the spreadsheet layout used in [[Smartsheet]].

## Key Features
- Customizable boards
- Timeline views
- Gantt charts
- Automated notifications
- Task assignments
- Reporting dashboards

These features help teams manage responsibilities and communicate progress.

### Project Boards
One useful feature is the project board. Project managers can create tasks, assign owners, set deadlines, and update progress using different status categories. This makes it easier to identify completed work and activities that still need attention.

## Pros and Cons
Monday.com is visually organized, easy to understand, and helpful for collaboration. However, more advanced features require paid plans, and managing complicated projects can require additional customization.

## My Experience
At Cummins, I participate in weekly engineering meetings where we discuss project progress, upcoming milestones, and outstanding action items. Part of my responsibility is tracking these items and following up with team members to make sure activities are completed. Monday.com would help me organize these responsibilities through task boards and automated reminders. For example, I could create tasks for supplier updates, prototype purchasing, and laboratory testing. The visual boards would make it easier to identify overdue activities and communicate updates during meetings. This would help improve organization and accountability across the project team.
